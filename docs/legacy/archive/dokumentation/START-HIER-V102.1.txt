INSTALLATION
1. Aktuelles Webverzeichnis sichern.
2. Inhalt der Direktupdate-ZIP in das Hauptverzeichnis der Website hochladen.

4. Browser hart neu laden / Cache leeren.
5. Website und Orgaboard öffnen.
