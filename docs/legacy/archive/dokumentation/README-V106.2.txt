RÄUCHERHAKEN24 V106.2 · KI-PRODUKTBESCHREIBUNG + SEO

Neu im Orgaboard Produkt-Baukasten:
- KI-Produktredaktion in Schritt 3
- Beschreibung optimieren
- Beschreibung + SEO gemeinsam optimieren
- Zielgruppe: Alle / Einsteiger / Erfahrene / B2B
- Ton: professionell / technisch / einfach
- KI darf nur vorhandene Produktfakten verwenden
- Vorschläge werden zuerst in die Felder übernommen und NICHT automatisch gespeichert

SEO in Schritt 5:
- Live-SEO-Score 0–100
- Prüfung von Produktname, Kurzbeschreibung, Langtext, Vorteilen, SEO-Titel und Meta-Beschreibung
- KI-SEO-Optimierung
- interne Fokusbegriffe
- SEO-Titel + Meta-Beschreibung werden im Shop synchronisiert
- Produktdetailseiten erhalten Canonical und Product Structured Data

Server:
- verwendet dieselbe serverseitige OPENAI_API_KEY-Konfiguration wie Smoky
- optional: OPENAI_PRODUCT_AI_MODEL
- ohne API-Konfiguration zeigt das Orgaboard eine klare Fehlermeldung; Produktbearbeitung bleibt vollständig nutzbar

Sicherheit:
- Login + edit_products-Berechtigung erforderlich
- CSRF-Schutz
- API-Schlüssel bleibt ausschließlich serverseitig
- keine automatische Veröffentlichung von KI-Texten
