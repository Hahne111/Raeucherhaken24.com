SMOKY LIVE-KI – V17

Die Website ist für Live-KI vorbereitet.

WICHTIG:
- Der OpenAI API-Schlüssel darf NICHT in HTML oder JavaScript stehen.
- smoky-api.php liest den Schlüssel ausschließlich serverseitig aus OPENAI_API_KEY.
- Der Endpunkt nutzt die OpenAI Responses API und Websuche.
- Smoky soll recherchierte Informationen NICHT kopieren, sondern vollständig neu und auf Räucherhaken24 zugeschnitten formulieren.
- Falls die API auf dem Server noch nicht konfiguriert ist, nutzt die Oberfläche eine lokale Fallback-Beratung.
